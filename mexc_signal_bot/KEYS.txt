============================================
КУДИ ВСТАВЛЯТИ КЛЮЧІ
============================================

1. Скопіюй файл .env.example і назви його .env

2. Відкрий файл .env і вставь свої дані:

TELEGRAM_BOT_TOKEN=123456:ABCDEF...

# (опційно, тільки read-only)
MEXC_API_KEY=
MEXC_API_SECRET=

3. Збережи файл .env

4. Запусти бота командою:
   python bot.py

5. У Telegram напиши боту:
   /session

============================================
ВАЖЛИВО
============================================
- Файл .env НІКОЛИ не заливай на GitHub
- Не надсилай токен мені в чат
- Токен береться тільки з твого локального .env
